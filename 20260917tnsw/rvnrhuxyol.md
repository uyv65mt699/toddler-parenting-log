# 刘波说影像丨患了肩周炎，X 光和磁共振（MR）如何选择？

> 更新时间：2026-09-17 (UTC+8)

**开栏语**
影像检查技术（如DR、CT、MR、超声及核医学等）在临床已经普遍应用，对疾病诊断、治疗及预后指导发挥了重要作用。如何选择众多影像检查手段，如何解读影像报告，是广大患者迫切需要了解的知识。广东省中医院影像科刘波教授将通过《刘波说影像》专栏定期推送疾病影像最新进展以及相关科普知识，为您传道解惑。欢迎您持续关注！

肩周炎，又称“五十肩”“冻结肩”，主要症状是肩部疼痛和活动受限，给患者日常生活带来诸多不便。在肩周炎的诊断和治疗中，影像检查是重要的诊断手段，其中X 光和磁共振较为常用，它们各有优势与不足。

**X 光检查**

X 光检查简单又常见，就像给身体拍平面照片。检查速度快，短短几分钟就能完成。在诊断肩周炎时，X 光可以清晰呈现出肩关节的骨骼形态。比如，医生能通过它看出肩部有没有骨折、脱位，或者是骨头有没有骨质增生、钙化这些比较明显的骨骼问题。要是肩膀曾经受过外伤，X 光就能快速判断骨骼的状况。
不过，X 光也有明显的短板。它只能看到骨骼的大致情况，对于肩周炎中常见的软组织病变，像肩袖损伤、肌腱炎、滑囊炎等，X 光就显得力不从心了。因为这些软组织在 X 光片上成像不明显，很难分辨出是否存在病变。

**MR 检查**
与 X 光检查相比，磁共振（MRI）在检查和诊断肩周炎方面有着独特的优势。**1、清晰显示肩部软组织**肩周炎患者常伴有肩袖、肌腱、韧带等软组织的病变。肩袖是由冈上肌、冈下肌、肩胛下肌和小圆肌的肌腱组成，对维持肩关节的稳定性和正常活动至关重要。在肩周炎的发展进程中，肩袖损伤颇为常见。通过磁共振检查，医生可以精准地观察到肩袖是否存在撕裂、磨损以及退变的程度。哪怕是极其细微的损伤，在磁共振成像下也无所遁形，为后续的治疗决策提供关键依据。如果肩袖损伤较轻，医生可能会建议采用保守治疗，如药物治疗、物理治疗等；而对于损伤严重的患者，则可能需要进行手术修复。**2、直观呈现肩关节囊和滑膜病变**在肩周炎发作时，关节囊往往出现增厚现象，滑膜也会产生炎症。磁共振成像能够清晰地显示出关节囊增厚的具体程度以及滑膜炎症的范围。这些详细的信息有助于医生准确评估病情的严重程度，从而制定出个性化的治疗方案。同时，医生还可以依据这些检查结果，对病情的发展趋势进行有效的预判，及时调整治疗策略，以达到最佳的治疗效果。**3、在鉴别诊断方面，磁共振检查同样有着重要价值**肩部疼痛的原因多种多样，除了肩周炎之外，还可能是颈椎病、肩部肿瘤等其他疾病。由于不同疾病的治疗方法差异较大，准确的鉴别诊断至关重要。磁共振成像能够清晰地展示肩部及周围组织的详细结构，帮助医生从多个角度对病变进行观察和分析，从而准确地区分肩周炎与其他疾病，避免误诊误治的情况发生，让患者能够得到及时、有效的治疗。磁共振检查就像是医生的“透视眼”，为肩周炎的诊断和治疗提供了全面、准确的信息。它不仅帮助医生更深入地了解患者的病情，还为制定科学合理的治疗方案奠定了坚实基础，极大地提高了肩周炎的诊疗水平，为广大患者带来了康复的希望。
